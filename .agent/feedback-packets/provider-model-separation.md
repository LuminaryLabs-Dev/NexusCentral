# Provider And Model Separation Feedback

Status: active

## Feedback

- Router is for providers such as OpenRouter, NVIDIA NIM, LM Studio, OpenAI, Google, and compatible endpoints.
- Router should expose a complete but minimal provider configuration.
- Models needs its own page for downloading and loading local models.
- A loaded local model may be added to Router as a local provider, but model lifecycle remains service-owned separately.
- Write code now and defer feature validation into repository docs.
