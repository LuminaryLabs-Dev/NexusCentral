# Profile Submission Bundle Exporter

Status: complete

## Purpose

Turn the full idea profile pack into a one-go submission bundle, with optional filtered selection for smaller handoffs.

## Criteria

- Active: The exporter can emit the full pack in one file.
- Active: The exporter can emit a filtered subset by id or limit.
- Active: The exporter keeps both JSON and a compact markdown handoff under `.agent/use-case-catalog/`.
- Active: The exporter does not require any changes to the NexusCentral app tree.
