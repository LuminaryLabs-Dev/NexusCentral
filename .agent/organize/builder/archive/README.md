# Archive Guidance

Use `archive/` for retired, superseded, or historical material that should no longer participate in the live workflow inventory.

Do not use `archive/` for:

- paused workflows that may return
- unresolved drafts that still need active review
- empty placeholder material

Keep those items in `automations/disabled/` or `automations/experimental/` instead.
