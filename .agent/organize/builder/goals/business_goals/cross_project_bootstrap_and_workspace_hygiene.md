# Business Goal: Cross-Project Bootstrap And Workspace Hygiene

- `business_goal_id`: `cross_project_bootstrap_and_workspace_hygiene`
- `priority`: `medium`
- `goal_statement`: Reduce friction when bootstrapping new repos, curating sprawling workspaces, and deciding what should stay active, archived, or mirrored.
- `why_it_matters`: The surrounding GitHub directory contains active products, stubs, archives, prototypes, and meta-doc repos. Without better hygiene, portfolio planning and workflow seeding both degrade.
- `supporting_projects`: `LuminaryLabs`, `LuminaryWiki`, `NexusCentral-Builder`, `NexusFactoryFactory`, `NexusTestProject`, `FlyBoys`, `HorrorCorridor`, `LuminaryAssets-Dec2025`, `ArduinoSanoboxing`.
- `manual_effort_reduced`: Repeated setup briefs, repo classification, empty-repo triage, and scaffold selection work.
- `suggested_workflow_focus`: Setup automations, cleanup automations, archive classification, and template recommendation workflows.
