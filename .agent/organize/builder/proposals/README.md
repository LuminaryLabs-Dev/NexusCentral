# Proposal Library

## Purpose

This directory is the curated home for staged workflow proposals and tool proposal records that are important enough to keep as part of the planning library.

## Placement Rules

- Put staged workflow proposal records in `proposals/workflow_proposals/`.
- Put staged tool proposal records in `proposals/tool_proposals/`.
- Keep run-generated follow-up queues in `improvements/proposals/`.
- Keep short goal briefs in `goals/workflow_targets/`.

## Current State

As of `2026-03-25`, the proposal library contains:

- workflow proposals under [`proposals/workflow_proposals/`](../proposals/workflow_proposals/)
- tool proposal records under [`proposals/tool_proposals/`](../proposals/tool_proposals/)

The workflow proposals remain staged. The tool proposal records currently act as proposal provenance for live tool contracts under [`tools/experimental_tools/`](../tools/experimental_tools/) and [`tools/final_tools/`](../tools/final_tools/).

Keep goal-linked workflow target briefs under [`goals/workflow_targets/`](../goals/workflow_targets/) and run-generated follow-up queues under [`improvements/proposals/`](../improvements/proposals/).
