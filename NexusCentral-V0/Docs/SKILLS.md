# Skills

## Overview
Skills are domain-specific workflows that provide specialized patterns, guidance, and best practices for targeted development tasks.

## Available Skills
- [catalog-management-it](../.github/skills/catalog-management-it/SKILL.md) - Use when adding, importing, validating, or querying catalog entries.
- [execution-runtime-it](../.github/skills/execution-runtime-it/SKILL.md) - Use when implementing async execution, progress reporting, or runtime orchestration.
- [desktop-mvvm-it](../.github/skills/desktop-mvvm-it/SKILL.md) - Use when editing Avalonia MVVM view models, bindings, or desktop UI state.
- [workflow-modeling-it](../.github/skills/workflow-modeling-it/SKILL.md) - Use when designing workflow YAML, validating workflow models, or importing definitions.
- [app-paths-it](../.github/skills/app-paths-it/SKILL.md) - Use when resolving app paths or migrating state locations.
- [automations-execution-it](../.github/skills/automations-execution-it/SKILL.md) - Use when building the Automations tab or chaining multi-file step execution.

## Note
These are workspace-level skills for this repository. Mirror them into your personal Copilot skill folder later if you want the same behavior across other projects.
