# Ten Hour 2D RPG Scaffold

This is a browser-playable Vite scaffold for a 2D RPG planned around a ten-hour content runway.

## Run

```bash
npm install --no-audit --no-fund
npm run dev
npm run build
```

## Signal Flow

The compiled scaffold proves:

```text
boot -> title/menu -> new game -> world map -> player movement -> NPC interaction -> quest log update -> inventory update -> combat encounter placeholder -> save/load placeholder -> return to menu
```
