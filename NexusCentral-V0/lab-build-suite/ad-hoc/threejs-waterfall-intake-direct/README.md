# Neon Runner 3D

A polished, browser-playable 3D infinite runner game built with Three.js and Vite.

## Features

- **Immersive 3D Graphics**: Built with Three.js featuring neon aesthetics, dynamic lighting, and particle effects.
- **Responsive Controls**: Smooth keyboard controls (Arrow keys or WASD) for lane switching.
- **Progressive Difficulty**: Game speed increases over time, testing your reflexes.
- **Complete Game Loop**: Start screen, real-time HUD, and Game Over summary.
- **Zero External Assets**: All geometry and materials are generated procedurally—no images or models to download.
