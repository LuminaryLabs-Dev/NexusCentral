Build a browser-playable Three.js marble obstacle game called Marble Temple. Use a multi-file Vite project with Three.js as a package dependency, not a CDN. The player controls a marble through ramps, bridges, pickups, hazards, and a temple finish gate. Include lighting, camera follow, physics-like movement, level geometry, HUD, pause, restart, win/fail states, and keyboard controls. One main Three.js gameplay source file must be at least 500 lines long.
