# Direct Intake Decisions

## 2026-07-31: Local State, Shared Routing Only

Source: user direction during NexusCentral decision intake.

- Treat each local computer as its own NexusCentral user/node.
- Keep all user/workspace state local to that computer: conversations,
  workflows, runs, memory, sandboxes, artifacts, approvals, and credentials.
- Do not synchronize that state between computers.
- Share only model-routing data: route requests, model/provider availability,
  and routing outcomes.
- Resolve shared-routing topology, enrollment, access control, retention, and
  failure recovery through subsequent intake questions.
