# Goal Evidence

Evidence belongs to the matrix node it proves and is classified as `observed`, `weak`, `missing`, or `contradictory`.

Each evidence record should identify:

- the node and matrix revision;
- the acceptance claim it tests;
- the command, runtime, browser, or artifact reference;
- the observed result and timestamp;
- the owner and next repair action when the claim is not proven.

Plans, counts, compiles, and intentions do not promote a feature without direct behavioral evidence.
