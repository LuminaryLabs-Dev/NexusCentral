# Start Here

1. Read `../goal.md`.
2. Read `../docs/00-START-HERE.md` and its linked documents in order.
3. Identify the first incomplete phase in `../docs/08-IMPLEMENTATION-SEQUENCE.md`.
4. Take only the next bounded action allowed by that phase.
5. Run the required proof from `../docs/09-VALIDATION-PROMOTION-GATES.md`.
6. Record durable progress or blockers in `../memory.md`.
7. Repeat until every promotion gate is satisfied.

Do not create another Electron UI, bypass adapter boundaries, move secrets into
DSKs, or claim parity from static checks alone.
