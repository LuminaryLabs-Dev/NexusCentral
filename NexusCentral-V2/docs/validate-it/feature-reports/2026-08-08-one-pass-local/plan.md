# Validation Plan

Source: `/Users/crimsonwheeler/.codex/attachments/5aa1622c-6a90-4031-bdce-6038efdfaa23/pasted-text.txt`

Validate these proof surfaces independently:

1. Matrix execution engine: schema, dependencies, CLI projection, transitions, and queue authority.
2. Default LFM runtime: endpoint, model identity, provider health, inference, and fail-closed behavior.
3. Local node and workspace: launch, local authority, persistence, restart, and visible Work surface.
4. Routing: candidate selection, failure, retry, cancellation, recovery, and scale.
5. Harness and workflows: NexusAgent import, profile enforcement, sandboxing, stages, and approval gates.
6. Proof and artifacts: run state, hashes, provenance, read/download, audit, and validation evidence.
7. UI and service: human-visible surfaces, empty/error states, service controls, and launch state.
8. Combined milestone: one live LFM request through routing with persisted output and proof.

Pass requires direct behavioral evidence. Static code, plans, and build success are supporting evidence only.
