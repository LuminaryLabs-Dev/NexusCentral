# NexusCentral Public Downloads Site

The public downloads page is generated by `.github/workflows/nexuscentral-pages.yml`.

## Shape

- Pushes to app, package, update, or workflow files build the configured targets.
- The workflow stores the latest successful downloads for the pushed branch under `gh-pages`.
- The generated Pages site contains:
  - `index.html`
  - `README.md`
  - `downloads/index.json`
  - `downloads/<branch>/latest/*.zip`
  - `downloads/<branch>/latest/*.size.json`

## Setup Required In GitHub

Set repository Pages source to:

- Source: deploy from branch
- Branch: `gh-pages`
- Folder: `/`

The workflow creates or updates `gh-pages` automatically.

## Size Expectation

The current full target set is about 220 MB zipped per branch for one buildable lane. Each additional branch keeps its own latest downloads, so Pages storage grows roughly by that amount per active branch.
